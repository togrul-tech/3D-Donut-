For using this code:

1. Create a c++ file named donut  ->  donut.cpp
2. Paste the code
3. Press ctrl + ` at the same time. It will open terminal of your IDE
4. Type your "g++ donut.cpp". (don't forget to check your file adress, if it's in another folder just type "cd your_folder_name")
5. Then type "./a.exe".


DONE!!! Now you can watch your donut spinning!
